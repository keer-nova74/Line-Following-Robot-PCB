## Line-Following Robot PCB

## Overview
A line-following robot PCB designed using KiCad as a robotics hardware learning project.

## Project Objectives
- Design a custom PCB for a line-following robot.
- Interface infrared sensors with a microcontroller.
- Integrate a dual DC motor driver.
- Design suitable power supply connections.
- Create a schematic and PCB layout using KiCad.

## Planned Features
- Microcontroller interface
- Infrared line-detection sensors
- Dual motor driver circuit
- Motor output connectors
- Power input and regulation
- Programming and debugging connections

## Design Tools
- KiCad — schematic capture and PCB layout

## Project Status
In Progress — schematic design, component selection, PCB layout, and design-rule checking will be completed as the project develops.

## Future Work
- Complete the schematic.
- Assign footprints to components.
- Design a two-layer PCB.
- Perform electrical rule checks (ERC) and design rule checks (DRC).
- Generate Gerber files after validating the layout.
